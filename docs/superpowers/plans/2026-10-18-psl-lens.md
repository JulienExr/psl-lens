# PSL Lens Implementation Plan

> Exécution directe autorisée par la mission; skill executing-plans et revue indépendante finale.

**Goal:** livrer l’application locale décrite dans la mission.
**Architecture:** UI séparée des moteurs purs, MediaPipe isolé dans un worker et assets locaux.
**Tech Stack:** React, strict TypeScript, Vite, Tailwind v4, MediaPipe, Vitest, Playwright.
**Spec:** `docs/superpowers/specs/2026-10-18-psl-lens-design.md`.

## Contraintes globales

Aucun push/déploiement. Aucun upload facial. Pas de résultat simulé en production.
Texte obligatoire: Experimental PSL estimate — not a scientific beauty rating.
Profil non validé = score global indisponible, aucune valeur absente remplacée.

## Review Focus

1. Navigation/effacement pendant initialisation ou inférence: arrêter le flux, ignorer résultat périmé.
2. Plusieurs visages: rejet réel, jamais choisir discrètement le premier.
3. Portrait/paysage/miroir: overlay et distances dans le bon repère.
4. Scan immobile ou pose incorrecte: aucune progression inventée.
5. Rapport sans profil: score total null, sous-scores explicables.

## Interfaces

`src/types/index.ts`: Landmark, FacePose, FaceDetectionResult, CaptureQuality,
Measurement, ScanObservation, AggregatedAnalysis, PSLResult.
`measure(result,quality)` retourne Measurement[]; `aggregate(observations)`
retourne AggregatedAnalysis; `score(measurements)` retourne PSLResult.
`visionClient.detect(bitmap,mode,timestamp)` retourne FaceDetectionResult.
Les vues reçoivent `onReport(analysis)` et le rapport reste en mémoire App.
