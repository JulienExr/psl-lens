# PSL Lens V2 — implementation contract

Base: merged PR #2, stable commit 84bf44b. Baseline: 142 unit/component, 21 Chromium, 2 alternate-engine, 1 production PWA, 8 update and 1 performance tests pass; lint, types, format, build, audit pass.

1. Profile engine: independent 2D geometry from explicitly confirmed manual landmarks on a real lateral photo. User declares anatomical side and capture orientation; image-facing direction is computed separately. No blind 90° MediaPipe inference. Test similarity transformations, mirroring, missing and degenerate inputs.
2. Profile workflow: local import or explicit live frame capture, zoom/pan, point placement/drag, undo/reset, keyboard/numeric adjustments, explicit validation. Keep results separate by view. Advanced scan reuses existing real front/oblique acquisition and offers assisted lateral capture.
3. Multiview protocol: separate version/config, inspectable contributions and coverage, deterministic selection of one profile; retain frontal estimate when lateral data is missing. Add provenance and versioned JSON.
4. Independent modules: local native PDF with opt-in photos/scores/technical detail; deterministic recommendations from declared preferences; optional lightweight estimated-geometry explorer. Freeze shared types in src/types/v2.ts before delegating these modules.
5. Validation: public-domain lateral fixture, annotation/evaluation infrastructure, repeatability and geometric checks. Document actual results and dataset gaps without claims of scientific aesthetic validation.
6. Integration: mobile/accessibility, progressive module caching, documentation, full verification and independent review. Push dedicated branch and create/attach PR; no merge or public deployment.

PDF, recommendations and geometry explorer may be developed in parallel in disjoint files. Parent owns application integration, dependencies, profile engine, scoring and shared types.
